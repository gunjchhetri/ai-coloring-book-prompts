Tips for good habits & manners coloring book

  • Show one child doing one habit per page; the caption then reinforces exactly what the picture shows.
  • Phrase habits as actions ('washing hands', 'saying thank you') so each page is easy to draw and to talk about.
  • Use the book as a routine chart: color the habit on the day the child practises it.
