# How to use these prompts

Every prompt in this library is a complete brief for one book: who it is for, how many pages, the page size, the style and what goes on the pages. Here are the three ways to use one.

## 1. One click on InkChamps (fastest)

Each prompt has a **Make this book on InkChamps** button. It opens the [InkChamps](https://inkchamps.com/?utm_source=github&utm_medium=prompt_library&utm_campaign=ai-coloring-book-prompts&utm_content=guide-howto) creator with the brief already filled in.

1. Click the button under the prompt you like.
2. Check the age and page count against the prompt's settings, and choose Standard or Premium quality.
3. Press create. InkChamps plans every page, draws them at the right line weight for the age, and builds a print-ready PDF.
4. Read the pages, redraw any you want changed, and download the PDF for Amazon KDP, Etsy or your home printer.

Each prompt lists its cost in InkChamps credits at both quality levels, so you know before you start.

## 2. Copy the brief into any AI tool

Press **Copy** (or select the text in the grey box) and paste it into ChatGPT, Gemini, Claude or an image generator. The briefs describe the pages, not one tool's settings, so they work anywhere as a starting point. In a single-image tool, ask for one page at a time and keep the age and style the same on every page.

## 3. Let an AI agent order it

Every prompt has an **Exact settings for AI agents** section with the precise InkChamps MCP call. An agent connected to InkChamps can place that order for you and hand back the PDF. See [Order books from AI agents](ai-agents-mcp.md).

## Make a prompt your own

- **Change the subjects, keep the shape.** Swap "dinosaurs" for "sloths" and keep the list of concrete scenes.
- **Keep the age band.** The four bands are 3-6, 6-9, 9-13 and 13+. Line weight, detail and background change with each.
- **List books stay one item per page.** If you add a letter, number or habit to a list, add a page too.
- **Name your own characters.** A name and one or two visual details ("Pip, a small red fox with a blue scarf") keep a character the same on every page.
- **Stay original.** Use your own characters, never ones from films, games or toys, if you plan to sell the book.
